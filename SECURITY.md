# Sicherheit

Sicherheitsprobleme bitte nicht öffentlich melden. Bis ein privater Security-Kanal im GitHub-Repository eingerichtet ist, den Maintainer über die im Plugin-Header angegebene Website kontaktieren.

Unterstützt wird jeweils die aktuelle Release-Linie. Updates sollten zeitnah eingespielt werden.

Das Plugin lädt Inhalte ausschließlich von den in der Architekturdokumentation genannten Bundestag- und CDN-Hosts. Änderungen an dieser Allowlist sollten als sicherheitsrelevant geprüft werden.
